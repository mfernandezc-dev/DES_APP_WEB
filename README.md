# Módulo de Ventas - Spring Boot

## Descripción

Proyecto desarrollado para la implementación de un sistema de ventas utilizando Java con Spring Boot, JPA e integración con MySQL.

El sistema permite administrar productos, categorías, clientes, empleados, ventas y detalles de venta mediante operaciones CRUD.

---

## Tecnologías utilizadas

- Java
- Spring Boot
- Spring Data JPA
- MySQL
- SQLyog
- Maven
- Postman
